交互演示 · 主流程分步走查

点击下方任一步骤，右侧舞台会切换到对应屏幕并高亮关键元素。

主流程说明

本演示串起产品最核心的一条链路：浏览卡片 → 打开 A4 文档详情 → 调整预览 → 进入配置态排版 → 保存。

  1. 浏览态：卡片墙按四槽位渲染，含 hover 悬浮预览气泡与增量加载骨架卡。
  2. 详情：右侧 860px 抽屉内的 Word 式 A4 分页文档（本产品核心卖点）。
  3. 缩放与翻页：0.5~1.5 倍缩放、「适应宽度」、吸顶页码指示器。
  4. 配置态：卡片排版 / 文档排版双模式三栏编辑器，拖拽落位 + 插入指示线。
  5. 保存：写入视图级配置（原型仅演示交互，不含持久化）。

提示：演示仅切换原型屏幕，不会修改任何真实数据。
